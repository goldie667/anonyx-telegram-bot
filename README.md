# ANONYX — HOKAS Free build

Русскоязычный Telegram-бот для анонимного общения. Эта сборка адаптирована для HOKAS Free:
- Python 3.12+
- aiogram 3.13
- MySQL 8.0 через SQLAlchemy + aiomysql
- без Redis и Docker
- временная очередь поиска, активные пары и FSM хранятся в памяти процесса

## Важно об ограничениях HOKAS Free

HOKAS Free показывает лимит времени работы (например, 12 часов) и 256 MB RAM. Поэтому эта сборка предназначена для разработки и тестирования, а не гарантирует доступность 24/7. Очередь поиска и активные чаты сбрасываются при перезапуске процесса; профили, жалобы и блокировки сохраняются в MySQL. Запускайте только один экземпляр бота.

## Настройка в HOKAS

1. Выберите Python 3.12, если HOKAS позволяет Redeploy на другую версию.
2. Загрузите содержимое этой папки в каталог `anon_telegram_bot`.
3. В разделе Database создайте MySQL database. Используйте значения Host, Port, Database и Username из панели HOKAS.
4. В разделе Manage → Environment Variables добавьте:
   - `BOT_TOKEN` — новый токен от @BotFather (не публикуйте его).
   - `BOT_USERNAME` — имя бота без `@`.
   - `DB_HOST=127.0.0.1`
   - `DB_PORT=3306`
   - `DB_NAME` — имя базы из HOKAS.
   - `DB_USER` — пользователь базы из HOKAS.
   - `DB_PASSWORD` — пароль базы из HOKAS.
   - `ADMIN_IDS` — ваш числовой Telegram ID (не username).
5. Установите зависимости из `requirements.txt`.
6. В качестве команды запуска используйте из корня проекта:
   `cd anon_telegram_bot && python3 -m bot.main`

Если поле HOKAS «File to run» требует путь к файлу, а не команду, откройте каталог `anon_telegram_bot` и укажите `bot/main.py`; зависимости всё равно должны быть установлены.

## Безопасность

- Не добавляйте `.env` в публичный репозиторий.
- Не отправляйте BOT_TOKEN и DB_PASSWORD в чаты или скриншоты.
- Если токен когда-либо раскрывался, отзовите его через @BotFather и создайте новый.
- Перед публичным запуском проверьте правила модерации, приватность и нагрузку.

## Функции

- анкета 18+ (возраст, пол, страна, интересы)
- случайный поиск собеседника с фильтрами
- анонимная пересылка сообщений
- следующий собеседник / завершение
- жалоба и блокировка
- Premium за Telegram Stars
- админ-панель: статистика, жалобы, ban/unban, рассылка

Это тестовая версия. Перед массовым запуском нужны полноценные интеграционные тесты и проверка поведения при сетевых сбоях.
